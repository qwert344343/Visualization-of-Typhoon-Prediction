一、快速启动
────────────────────────────────────────────
【方式0：便携版（最简单，推荐）—— 仅限 Windows 10/11 64位】
   双击本文件夹里的「启动台风监测.bat」即可：
   · 已内置 Node 运行时（runtime/node.exe），目标电脑无需安装任何软件
   · 自动挑选空闲端口（8080 → 8081 → 8082），多开不冲突
   · 自动启动服务并打开浏览器
   · 停止方法：关闭弹出的「台风WebGIS服务」黑色窗口
   · 首次运行如弹出 Windows 防火墙提示，勾选"专用网络"并允许，
     这样同一 WiFi 下的手机/平板/其他电脑也能通过
     http://<这台电脑的IP>:8080 直接访问页面

【方式1：本地运行（需已安装 Node.js 18 及以上）】
   1. 打开命令行（CMD 或 PowerShell），进入本文件夹：
        cd "C:\Users\15503\Desktop\台风实时监测WebGIS"
   2. 启动服务（无需 npm install，零依赖）：
        npm start
   3. 浏览器访问：  http://localhost:8080

【方式2：Docker 部署（需 Docker Desktop 正在运行）】
        docker compose up -d --build
   访问地址同上。数据与瓦片缓存保存在 Docker 卷中。
   ※ 若拉取 node:24-alpine 失败，可改用本地已有基础镜像：
        docker build --build-arg NODE_IMAGE=node:22-alpine -t typhoon-webgis .
        docker run -d -p 8080:8080 typhoon-webgis

【修改端口】默认 8080，若被占用可换端口启动：
        CMD:      set PORT=8081 && npm start
   PowerShell:  $env:PORT=8081; npm start
   (便携版 bat 内改 set PORT=8080 那一行)

※ 注意：本机若已有该系统在运行（如 8080 端口占用），先换端口或先
   关闭旧实例（任务管理器结束 node.exe）。

二、页面功能说明
────────────────────────────────────────────
【界面布局】顶栏=连接状态/更新时间/刷新按钮；左侧=台风列表与图层
   控制；中间=地图；右侧=台风详情；底部=路径回放条。

【看实时台风】打开页面自动加载西太平洋/南海当前全部活跃台风。
   · 彩色折线＝历史路径（颜色对应强度：黄=热带低压、蓝=热带风暴、
     绿=强热带风暴、橙=台风、紫=强台风、红=超强台风）
   · 旋转风眼图标＝当前中心位置（点它或点左侧卡片查看详情）
   · 虚线圆圈＝七/十/十二级风圈；青色虚线＋圆点＝中央气象台预报

【路径回放】选中台风后点底部 ▶ 播放，可拖滑块跳到任意时刻，
   0.5×~4× 调速。回放时显示"该时刻实况 + 当时发布的预报"。
   「回到实时」恢复最新状态。

【台风详情】右侧面板：强度、气压、最大风速（含风力等级）、移向
   移速、风圈四象限半径、距沿海主要城市距离（<300km 橙色高亮）、
   中央气象台逐时效预报表。悬停地图轨迹点可看任一时刻数据。

【图层开关】左侧"图层与显示"：风圈、预报路径、24/48小时台风
   警戒线、全国气象预警（彩色菱形，点击看预警正文）、时间标注。

【切换底图】天地图矢量（默认，中文）/ 卫星影像 / 地形晕渲 /
   Esri 海洋 / Esri 影像 / OpenStreetMap。

【历史台风】左侧选年份（2015年至今）→ 查询 → 点列表加载完整
   路径。「返回实时」退出历史模式。

【数据更新】每 5 分钟自动向中央气象台拉取，有新定位点自动上图
   并弹提示；顶栏"刷新"可立即手动拉取；绿点＝实时连接正常。

【设置页面】点击顶栏 ⚙ 按钮打开设置：
   · 界面语言：中文 / English 一键切换
   · 布局模式：自动（按屏幕宽度）/ 桌面（始终平铺面板）/
     移动（始终抽屉式），手机与电脑布局自由切换
   · 主题外观：深色控制台 / 浅色（白底灰辅、橙色按钮）
   · 数据线路：自动（按所在时区）/ 中国（默认天地图底图）/
     海外（默认 Esri 海洋底图）。台风数据统一来自中央气象台
     免费公开接口，国内外均可访问；切换线路只影响底图选择，
     保证全球用户加载速度。
   以上设置自动记忆，下次打开保持不变。

三、常见问题
────────────────────────────────────────────
【Q1 页面打开但没有台风？】
   当前西太平洋可能无活跃台风（冬半年常见），可用"历史台风查询"
   查看往年台风；左侧列表也会显示近期停编台风。

【Q2 底图空白/瓦片不显示？】
   底图经后端代理中央气象台获取，若网络不通请切换为 Esri 或
   OSM 底图。

【Q3 Docker 容器内提示"上游数据拉取失败 HTTP 500"？】
   Docker Desktop 会把容器流量转发到 Windows 系统代理（如 Clash），
   代理未运行时会失败。解决：启动本机代理，或在 Docker Desktop →
   Settings → Resources → Proxies 关闭"Use system proxy"，
   或改用方式1本地运行。

【Q4 上游偶发 fetch failed？】
   中央气象台 CDN 偶有抖动，系统已内置重试机制，30 秒后自动恢复，
   无需处理。

【Q5 页面提示"连接断开"/无法访问？】
   说明后台服务已停止。重新双击「启动台风监测.bat」即可恢复，
   页面会自动重连（左上角圆点变绿=已恢复）。
   若命令行窗口出现 EADDRINUSE/端口占用错误，bat 会自动换用
   8081/8082 端口，浏览器地址以窗口提示为准。

四、文件结构
────────────────────────────────────────────
   server/index.js    后端服务（HTTP/SSE 推送/瓦片代理/定时轮询）
   server/nmc.js      中央气象台接口客户端（拉取/解析/缓存）
   web/               前端页面（Leaflet 地图与界面）
   data/cache/        运行后自动生成的瓦片缓存（可随时删除）
   README.md          详细技术文档（架构 / API / 数据结构）
